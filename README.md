# Velociti Titan 9 Pro — Meta Ads Practice Landing Page

Landing page website modern untuk produk smartphone fiktif **Velociti Titan 9 Pro**. Proyek ini dibuat khusus untuk **kebutuhan belajar, simulasi, dan latihan Meta Ads** (Facebook & Instagram Ads), bukan untuk transaksi e-commerce sungguhan.

## 🛠️ Teknologi yang Digunakan
- **HTML5**: Struktur halaman semantik.
- **CSS3**: Styling modern menggunakan Flexbox, Grid, CSS Variables, serta desain responsif.
- **JavaScript Vanilla**: Hamburger menu, accordion FAQ, animasi *scroll*, serta Meta Pixel Event Listener.
